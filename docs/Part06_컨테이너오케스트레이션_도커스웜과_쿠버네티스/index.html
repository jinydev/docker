📁 Part 06. 컨테이너 오케스트레이션: 도커 스웜(Swarm) 클러스터, 스택 배포, 무중단 롤링 업데이트 & 쿠버네티스 (076 ~ 095)

대단원 개요: 오케스트레이션 원리, 매니저/워커 노드, 선언적 서비스와 레플리카 자가 치유, 오버레이 네트워크와 인그레스 라우팅 메시, Swarm vs Kubernetes 비교, docker stack deploy, docker config & secret, 노드 레이블 배치 제약, 롤링 업데이트(update_config)와 자동 롤백(rollback_config), Drain 모드와 Raft 고가용성

  • 권장 학습 일정: 10 ~ 12주차
  • 기반 범위: 12장(컨테이너 오케스트레이션: 도커 스웜과 쿠버네티스) & 13장(도커 스웜 스택 배포) & 14장(업그레이드와 롤백 자동화)

📋 본 파트 강의 목록 (총 20강)

  • 076 🎻🌐 컨테이너 오케스트레이션이란 왜 클러스터가 필요한가 - 서버 한 대가 정전으로 꺼지면 우리 회사 서비스도 끝인가요? 수십 대의 서버를 하나로 묶는 오케스트레이션!
  • 077 🐝🏰 도커스웜 클러스터구축 매니저노드와 워커노드 - 별도 프로그램 설치 없이 docker swarm init 단 한 줄로 내 도커 엔진을 엔터프라이즈 클러스터로 변신시키다!
  • 078 🛡️⚡ 도커스웜 서비스생성 선언적레플리카와 자동자가치유 - 실행 중인 컨테이너를 강제로 죽여(rm -f) 보자! 1초 만에 새 컨테이너를 부활시키는 스웜 서비스(docker service)!
  • 079 🕸️🌐 클러스터 오버레이네트워크와 인그레스 라우팅메시 - 1번 서버의 웹 컨테이너가 3번 서버의 DB 컨테이너와 어떻게 통신할까? 오버레이(overlay) 네트워크와 인그레스 라우팅 메시!
  • 080 ⚖️☸️ 도커스웜 vs 쿠버네티스 Kubernetes 아키텍처완벽비교 - 도커 스웜(Swarm)과 쿠버네티스(Kubernetes), 무엇이 같고 무엇이 다를까? 언제 무엇을 선택해야 하는가!
  • 081 ☸️📄 쿠버네티스 기초체험 컴포즈에서 K8s매니페스트로 - 우리가 만든 도커 이미지를 쿠버네티스(Deployment + Service) YAML 매니페스트로 변환해 읽어보자!
  • 082 📚🚀 도커스웜 스택배포 docker stack deploy와 운영컴포즈 - 수십 줄의 docker service create 명령 대신 컴포즈 파일 하나로 클러스터 전체에 스택(docker stack deploy) 배포하기!
  • 083 🗂️☁️ 스웜 컨피그객체 docker config를 이용한 중앙설정관리 - 워커 노드가 20대인데 설정 파일(nginx.conf, app.json)을 20대 서버마다 일일이 복사하실 건가요? docker config!
  • 084 🔐🛡️ 스웜 비밀값 docker secret 암호화저장소와 보안주입 - 매니저에서도 암호화 저장되고, 네트워크로도 암호화 전송되며, 컨테이너 RAM(tmpfs)에만 나타나는 docker secret!
  • 085 📌💾 클러스터환경의 퍼시스턴트볼륨과 노드레이블 배치제약 - 1번 노드에 DB 데이터가 있는데 컨테이너가 2번 노드로 날아가 버리면? 노드 레이블(labels)과 배치 제약(constraints)!
  • 086 🌐🧭 스웜클러스터의 스택관리원리 서비스 태스크 복제와글로벌모드 - 클러스터에 새 서버를 추가하자마자 모니터링 에이전트가 자동으로 설치된다! replicated 모드 vs global 모드
  • 087 🏆🏰 Part06 중간미션 컨피그와 시크릿이 적용된 고가용성스택배포 - Part 06 중간 미션! 스웜 Config + Secret + 리소스 제한 + 노드 레이블 배치 제약이 총망라된 운영 스택 배포!
  • 088 🔄🚀 애플리케이션 무중단업그레이드 프로세스와 오버라이드병합 - 서비스 점검 공지 화면 없이 낮 12시 피크 타임에도 안전하게 새 버전을 배포한다! 무중단 롤링 업데이트의 원리
  • 089 🎚️⏱️ 롤링업데이트 정밀제어 parallelism delay order - 새 컨테이너를 먼저 켜고 헌 컨테이너를 끌까(start-first), 헌 것을 먼저 끄고 켤까(stop-first)? update_config 완전 정복!
  • 090 ⏪🚑 불량배포 자동감지와 자동롤백 failure action rollback - 금요일 퇴근 직전 배포한 신버전에 치명적 버그가 있었다! 스웜이 알아서 이전 버전으로 되돌리는 자동 롤백(Auto-Rollback)!
  • 091 🧪⏪ 롤백설정의 세부튜닝과 장애시뮬레이션 실전검증 - 일부러 고장 난 이미지를 배포해 보자! 스웜이 실패를 감지하고 이전 버전으로 완벽히 자동 롤백하는지 눈으로 확인하기!
  • 092 🔧🚧 클러스터 노드유지보수 Drain모드와 무중단서버점검 - 3번 워커 노드 서버의 리눅스 커널 패치와 재부팅이 필요하다! 서비스 중단 없이 노드를 비우는 Drain 모드!
  • 093 👑⚖️ 스웜클러스터 고가용성 멀티매니저와 Raft합의알고리즘 - 워커 노드가 죽으면 매니저가 살려내는데, 만약 매니저 노드가 죽으면 어떡하죠? 홀수 멀티 매니저와 Raft 합의 알고리즘!
  • 094 🚑🎖️ 클러스터 장애복구 시나리오 리더노드이탈과 워커승격 - 매니저 노드 1대가 영구 고장 났다! 워커 노드를 매니저로 승격(promote)시키고 정족수 상실 시 강제 복구하기!
  • 095 🏆👑 Part06 실전미션 무중단롤링업데이트와 자동롤백 클러스터완성 - Part 06 종합 미션! 헬스 체크 + start-first 무중단 롤링 업데이트 + failure_action: rollback 스택 실전 검증!
