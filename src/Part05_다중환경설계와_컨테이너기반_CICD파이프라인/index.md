# 📁 Part 05. 다중 환경 구성(Dev/Test/Prod)과 컨테이너 기반 CI/CD 파이프라인 (062 ~ 075)

> **대단원 개요**: 프로젝트 이름(-p) 격리, 컴포즈 오버라이드(override) 파일 병합, .env 변수 치환, 파일 기반 Secrets, YAML 앵커(&, *)와 확장 필드(x-), 컨테이너 기반 CI 인프라(Git + Registry + Jenkins/Runner), Docker-out-of-Docker 소켓 마운트, OCI 메타데이터 레이블, 자동화 품질 게이트
> 
> * **권장 학습 일정**: 9 ~ 10주차
> * **기반 범위**: 10장(도커 컴포즈를 이용한 여러 환경 구성) & 11장(도커와 도커 컴포즈를 이용한 애플리케이션 빌드 및 테스트)
