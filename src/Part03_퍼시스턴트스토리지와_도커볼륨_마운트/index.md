# 📁 Part 03. 퍼시스턴트 스토리지: 도커 볼륨(Volume)과 파일시스템 마운트 (032 ~ 041)

> 
> * **권장 학습 일정**: 5 ~ 6주차
> * **기반 범위**: 6장(도커 볼륨을 이용한 퍼시스턴트 스토리지 및 컨테이너 파일시스템 구조)
